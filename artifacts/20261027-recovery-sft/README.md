# 完整人工示范＋40 任务回放：恢复能力微调

## 实验问题

上一轮 PPO 在 12 个固定开发场景中，原 SFT 与 shaped PPO 均为 10/12，放置恢复均为 2/4；没有可证明的开发集提升。本轮检验：加入已有完整人工恢复示范，能否改善持碗对齐、松手与撤离，同时保留旧任务能力。

状态：数据与训练前检查完成，训练/评测结果待实际运行。不能据此宣称恢复能力已修复。

## 数据

只读复用旧项目中已批准的 10 条完整人工示范，共 2050 个控制帧。保留真实动作与 20 Hz 控制时序，没有视频加速、缩小动作或删掉必要夹持动作。预览见 `human-review/`；每段均保留最后松手和撤离。尾段记录显示原生任务成功、夹爪张开与末端离开；这属于原始采集记录检查，不是本轮独立重放验证。

人工数据来自 LIBERO spatial 的黑碗任务（公开训练集 task 36），本轮恢复开发场景来自 LIBERO goal task 8。二者机器人、动作和相机契约兼容，场景和语言不同。本实验检验跨场景迁移，不将这些示范冒称为当前失败初态的配对纠正数据，也不更改原始文字指令。

旧项目不做修改；草稿、此前慢动作片段和旧项目的公开训练划分不引入本轮，以免与当前留出集发生交叉。

## 固定训练方案

从本项目 40 任务 SFT 的 `multitask40_lora_v1/9999` 继续训练 LoRA，重新初始化优化器。2000 次更新、batch 1、seed 42、学习率 5e-6、20 步预热；25% 人工帧槽位＋75% 旧任务训练集回放，旧任务之间均衡。抽样后的实际比例会有有限样本波动；记录包含预取的样本计数。沿用官方归一化，不对小规模人工数据重新估计。

## 评测和晋级条件

训练前冻结 `evidence/recovery-sft28-evaluation-plan.json`：12 个已观察开发初态、6 个训练分布放置诊断和 8 个旧任务检查。恢复成功要求原生目标成立且连续 5 控制步无手指接触。所有模型均观察 5 步后重规划、10 个 flow 步、最多 300 个控制步。恢复留出 ID 10..13 保持隔离。

只有开发总数高于 10/12、放置高于 2/4、抓空和偏移各保留 4/4、旧任务保留 8/8，才达到预先定义的晋级门槛。本实验不会自动替换用户面板的模型。失败视频与成功视频一同保留。

## 复现

```bash
JAX_PLATFORMS=cpu .venv-train/bin/python scripts/train_recovery_replay.py --dry-run
.venv-train/bin/python -u scripts/train_recovery_replay.py
```
